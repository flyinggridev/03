# Flying Grid — Premium EV Charging Landing Page

A responsive, single-page English website for Flying Grid, designed with a premium dark EV-tech look and neon-green accents.

## Files
- `index.html` — complete responsive landing page (HTML, CSS and JavaScript included)
- `logo.png` — Flying Grid logo asset

## Preview locally
Open `index.html` in a browser. An internet connection is recommended for Google Fonts and the remote hero photograph.

## Publish on GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `logo.png`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; the public URL appears in the Pages section.
